# Contributing to Awesome AI × Crypto Tools

Thanks for your interest in contributing!

## Guidelines

1. **One tool per pull request** — keeps discussions focused
2. **Format**: `- [Tool Name](URL) - Brief description ending with a period.`
3. **No duplicates** — check if it's already listed
4. **Must be relevant** — AI + Crypto intersection
5. **Active project** — not abandoned (last commit < 1 year)

## How to Add

1. Fork this repo
2. Add your entry in the correct category
3. Submit a PR with a clear title: `Add [Tool Name] to [Category]`

## Quality Standards

- ✅ Open source or freemium with meaningful free tier
- ✅ Active development (commits in last 6 months)
- ✅ Good documentation
- ❌ No scam tokens or rug-pull tools
- ❌ No paid-only tools without free tier
